# Desafio 009 - Sistema de Pagamentos

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Validação de dados
- Busca de dados
- Filtragem de dados
- Cálculo de valores
- Validação de regras de negócio
- Tratamento de erros
- Uso de `throw`
- Uso de `try/catch`
- Uso de `Error` e `TypeError`
- Composição de funções
- Organização e separação de responsabilidades

## Regras

- Um pagamento deve ser localizado pelo seu ID.
- O ID informado deve ser um número.
- Caso o ID não seja encontrado, deve ser lançado um erro.
- O valor do pagamento deve ser maior que zero.
- Pagamentos com valor menor ou igual a zero são considerados inválidos.
- Apenas pagamentos com status `"aprovado"` e valor maior que zero devem ser considerados no faturamento.
- O faturamento total deve somar somente os pagamentos aprovados e válidos.
- O relatório deve informar os pagamentos aprovados, o faturamento total e a quantidade total de pagamentos.
