# Desafio 011 - Sistema de Relatório de Vendas

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Filtragem de dados
- Cálculo de valores
- Contagem de elementos
- Manipulação de objetos
- Uso de `filter()`
- Uso de `reduce()`
- Uso de `length`
- Uso de destructuring
- Composição de funções
- Separação de responsabilidades
- Organização de regras de negócio
- Tratamento de casos sem vendas aprovadas

## Regras

- Uma venda deve possuir produto, valor e status.
- Devem ser identificadas somente as vendas com status aprovado.
- O faturamento total deve ser calculado considerando somente as vendas aprovadas.
- A quantidade de vendas deve corresponder ao número de vendas aprovadas.
- O ticket médio deve ser calculado dividindo o faturamento total pela quantidade de vendas aprovadas.
- Caso não existam vendas aprovadas, o ticket médio deve retornar zero.
- Cada regra deve ser implementada em uma função específica.
- A função responsável pelo relatório deve reunir os resultados das funções auxiliares.
- O relatório final deve conter as vendas aprovadas, o faturamento total, a quantidade de vendas e o ticket médio.
- Os dados originais não devem ser modificados.
