# Desafio 007 - Validador de Acesso

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Tratamento de entradas
- Validação de dados
- Conversão de tipos
- Padronização de dados
- Regras de negócio
- Validação de dados numéricos
- Organização em funções
- Separação de responsabilidades
- Tomada de decisões

## Regras

- Todos os campos obrigatórios devem ser preenchidos.
- Campos vazios não são permitidos.
- Espaços desnecessários devem ser removidos dos campos de texto.
- O status da conta deve ser padronizado para letras minúsculas.
- A idade deve ser convertida para número.
- A idade deve ser um número válido.
- O usuário deve ter pelo menos 18 anos.
- A senha deve possuir no mínimo 8 caracteres.
- O status da conta deve ser `ativo` ou `inativo`.
- Contas com status `inativo` devem ter o acesso negado.
- O acesso deve ser permitido somente quando todos os critérios forem atendidos.
