# Desafio 012 - Sistema de Gerenciamento de Tarefas

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Busca de tarefas por ID
- Verificação de existência de tarefas por status
- Verificação de conclusão de todas as tarefas
- Validação de dados
- Atualização de objetos
- Contagem de elementos
- Manipulação de arrays e objetos
- Uso de `find()`
- Uso de `some()`
- Uso de `every()`
- Uso de `includes()`
- Uso de `map()`
- Uso de `filter()`
- Uso de `length`
- Uso de destructuring
- Uso do spread operator
- Composição de funções
- Separação de responsabilidades
- Organização de regras de negócio
- Tratamento de erros com `throw` e `try...catch`

## Regras

- Uma tarefa deve possuir ID, título e status.
- A busca deve retornar a tarefa correspondente ao ID informado.
- A verificação de existência deve identificar se há alguma tarefa com o status informado.
- A verificação de conclusão deve indicar se todas as tarefas possuem status concluído.
- Os status permitidos são `pendente`, `em andamento` e `concluida`.
- A atualização deve modificar somente o status da tarefa com o ID correspondente.
- Caso o status informado seja inválido, a operação deve lançar um erro.
- A atualização deve retornar um novo array, sem modificar os dados originais.
- Cada regra deve ser implementada em uma função específica.
- A função responsável pelo resumo deve reunir os resultados das funções auxiliares.
- O resumo final deve conter o total de tarefas, a quantidade de tarefas concluídas, pendentes e em andamento, além de indicar se todas estão concluídas.
