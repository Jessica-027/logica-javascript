# Desafio 008 - Sistema de Pedidos

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Busca de dados
- Filtragem de dados
- Cálculo de valores
- Verificação de condições
- Identificação de maior valor
- Composição de funções
- Organização em funções
- Separação de responsabilidades

## Regras

- Um pedido pode ser localizado pelo seu ID.
- Devem ser identificados todos os pedidos com status "pago".
- O faturamento total deve considerar somente os pedidos pagos.
- Deve ser verificado se existe pelo menos um pedido pendente.
- Deve ser identificado o pedido pago com maior valor.
- O resumo deve informar a quantidade total de pedidos e a quantidade de pedidos pagos.
- O relatório final deve reunir todas as informações calculadas.
