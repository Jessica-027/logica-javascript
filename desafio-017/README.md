# Desafio 017 - Sistema de Controle de Estoque

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Cálculo do valor em estoque de cada produto
- Filtragem de produtos com estoque baixo
- Identificação de produtos sem estoque
- Cálculo do valor financeiro total do estoque
- Cálculo do total de unidades vendidas
- Identificação do produto mais vendido
- Verificação da existência de produtos sem estoque
- Geração de relatório de estoque
- Manipulação de arrays e objetos
- Uso de funções independentes
- Uso de destructuring
- Uso de `filter()`
- Uso de `reduce()`
- Uso de `some()`
- Uso de `length`
- Separação de responsabilidades
- Organização de regras de negócio

## Regras

- Cada produto deve possuir identificador, nome, preço, quantidade em estoque e quantidade de unidades vendidas.
- O valor em estoque de cada produto deve ser calculado multiplicando o preço pela quantidade disponível.
- Produtos com estoque menor ou igual a 5 devem ser identificados como estoque baixo.
- Produtos com estoque igual a zero devem ser identificados como sem estoque.
- O valor financeiro total do estoque deve ser calculado somando o valor em estoque de todos os produtos.
- O total de unidades vendidas deve ser calculado somando as vendas de todos os produtos.
- O produto mais vendido deve ser identificado com base na maior quantidade de unidades vendidas.
- O sistema deve verificar se existe pelo menos um produto sem estoque.
- O relatório deve apresentar a quantidade de produtos cadastrados, o valor total do estoque, o total de unidades vendidas, o nome do produto mais vendido e a quantidade de produtos com estoque baixo.
- Cada regra deve ser implementada em uma função específica.
