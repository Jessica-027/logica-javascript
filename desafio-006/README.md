# Desafio 006 - Validador de Cadastro de Cliente

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Tratamento de entradas
- Validação de dados
- Conversão de tipos
- Regras de negócio
- Validação de dados numéricos
- Organização em funções
- Separação de responsabilidades

## Regras

- Todos os campos obrigatórios devem ser preenchidos.
- Campos vazios não são permitidos.
- Espaços desnecessários devem ser removidos dos campos de texto.
- A idade e a renda mensal devem ser números válidos.
- A idade deve ser maior ou igual a 18 anos.
- A renda mensal deve ser maior que zero.
- O cadastro deve ser recusado caso algum dos critérios obrigatórios não seja atendido.
- O cadastro deve ser aprovado somente quando todos os critérios forem atendidos.
