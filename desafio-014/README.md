# Desafio 014 - Sistema de Gerenciamento de Pedidos

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Listagem de pedidos
- Busca de pedidos por ID
- Filtragem de pedidos por status
- Cálculo do valor total dos pedidos
- Geração de relatório de pedidos
- Verificação de existência de pedidos por ID
- Validação de status
- Atualização de status de pedidos
- Contagem de elementos
- Manipulação de arrays e objetos
- Uso de `forEach()`
- Uso de `find()`
- Uso de `filter()`
- Uso de `reduce()`
- Uso de `some()`
- Uso de `map()`
- Uso de `includes()`
- Uso de `length`
- Uso de destructuring
- Uso do spread operator
- Separação de responsabilidades
- Organização de regras de negócio
- Tratamento de erros com `throw` e `try...catch`

## Regras

- Cada pedido deve possuir ID, cliente, valor, status e quantidade de itens.
- A listagem deve exibir o ID, o cliente, o valor e o status de cada pedido.
- A busca deve retornar o pedido correspondente ao ID informado.
- A filtragem deve retornar os pedidos que possuem o status informado.
- O valor total dos pedidos deve ser calculado somando o valor de cada pedido.
- O relatório deve apresentar o total de pedidos cadastrados e a quantidade de pedidos entregues, pendentes e em processamento.
- Os status permitidos são `pendente`, `processando` e `entregue`.
- A verificação de existência deve identificar se há um pedido com o ID informado.
- A atualização deve modificar somente o status do pedido correspondente ao ID informado.
- Caso o ID informado não exista, a operação deve lançar um erro.
- Caso o status informado seja inválido, a operação deve lançar um erro.
- A atualização deve retornar um novo array, sem modificar os dados originais.
- Cada regra deve ser implementada em uma função específica.
