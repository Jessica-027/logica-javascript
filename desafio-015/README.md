# Desafio 015 - Analisador de Desempenho de Jogadores

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Cálculo da participação dos jogadores em gols e assistências
- Filtragem de jogadores em destaque
- Cálculo da média de gols
- Identificação do artilheiro da competição
- Geração de resumo estatístico da competição
- Verificação de jogadores com muitas faltas
- Classificação de jogadores por participação
- Validação dos dados dos jogadores
- Manipulação de arrays e objetos
- Uso de `map()`
- Uso de `filter()`
- Uso de `reduce()`
- Uso de `some()`
- Uso de `every()`
- Uso de `length`
- Uso de destructuring
- Uso de operadores lógicos
- Separação de responsabilidades
- Organização de regras de negócio

## Regras

- Cada jogador deve possuir nome, quantidade de partidas, gols, assistências e faltas.
- A participação de cada jogador deve ser calculada somando gols e assistências.
- Um jogador será considerado destaque quando possuir pelo menos 9 participações em gols e assistências.
- A média de gols deve ser calculada dividindo o total de gols pela quantidade de jogadores.
- O artilheiro deve ser o jogador com a maior quantidade de gols.
- O resumo da competição deve apresentar o total de jogadores, o total de gols, o total de assistências e o nome do artilheiro.
- A verificação de faltas deve identificar se existe algum jogador com mais de 7 faltas.
- A classificação deve separar os jogadores em destaques e demais jogadores, conforme a quantidade de participações.
- A validação deve verificar se a lista de jogadores não está vazia.
- A validação também deve verificar se todos os jogadores possuem valores não negativos para gols e assistências.
- Cada regra deve ser implementada em uma função específica.
