# Desafio 019 - Sistema de Análise de Funcionários

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Filtragem de funcionários de acordo com o status de atividade
- Cálculo da folha salarial
- Extração dos nomes dos funcionários
- Filtragem de funcionários por departamento
- Processamento de análises utilizando callbacks
- Execução de diferentes operações por meio de callbacks
- Criação de Higher-Order Functions
- Criação de closures para preservar informações do escopo externo
- Utilização de funções retornadas por outras funções
- Manipulação de arrays de objetos
- Reutilização de funções
- Separação de responsabilidades

## Regras

- Cada funcionário deve possuir identificador, nome, salário, status de atividade e departamento.
- Os funcionários devem ser filtrados de acordo com seu status de atividade.
- A folha salarial deve ser calculada somando os salários dos funcionários.
- A extração dos nomes deve retornar um novo array contendo somente os nomes.
- A função de análise deve receber uma lista de funcionários e uma função callback.
- A função de análise deve executar a callback e retornar seu resultado.
- O sistema deve permitir executar diferentes análises utilizando a mesma Higher-Order Function.
- A função de criação de filtros deve receber um departamento e retornar uma nova função.
- A função retornada deve filtrar os funcionários de acordo com o departamento preservado pela closure.
- Cada regra deve ser implementada em uma função específica.
- O array original de funcionários não deve ser modificado.
