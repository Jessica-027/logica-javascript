# Desafio 013 - Sistema de Controle de Estoque

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Listagem de produtos
- Busca de produtos para reposição
- Cálculo do valor total do estoque
- Geração de relatório de estoque
- Verificação de disponibilidade de produtos
- Verificação de existência de produtos por ID
- Atualização de produtos
- Contagem de elementos
- Manipulação de arrays e objetos
- Uso de `forEach()`
- Uso de `filter()`
- Uso de `reduce()`
- Uso de `some()`
- Uso de `map()`
- Uso de `length`
- Uso de destructuring
- Uso do spread operator
- Separação de responsabilidades
- Organização de regras de negócio
- Tratamento de erros com `throw` e `try...catch`

## Regras

- Cada produto deve possuir ID, nome, quantidade, preço e estoque mínimo.
- A listagem deve exibir o nome e a quantidade em estoque de cada produto.
- Os produtos para reposição devem ser identificados quando a quantidade em estoque for menor ou igual ao estoque mínimo.
- O valor total do estoque deve ser calculado considerando a quantidade e o preço de cada produto.
- O relatório deve apresentar o total de produtos cadastrados, a quantidade de produtos disponíveis e a quantidade de produtos que precisam de reposição.
- A verificação de existência deve identificar se há um produto com o ID informado.
- A atualização deve modificar somente a quantidade do produto correspondente ao ID informado.
- Caso o ID informado não exista, a operação deve lançar um erro.
- A atualização deve retornar um novo array, sem modificar os dados originais.
- Cada regra deve ser implementada em uma função específica.
