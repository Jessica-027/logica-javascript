# Desafio 005 - Sistema de Análise de Bolsa Estudantil

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Tratamento de entradas
- Validação de dados
- Conversão de tipos
- Aplicação de regras de negócio
- Cálculo de renda por pessoa
- Organização em funções
- Separação de responsabilidades

## Regras

- Todos os campos obrigatórios devem ser preenchidos.
- O usuário pode cancelar a operação.
- Campos vazios não são permitidos.
- Valores numéricos devem ser válidos.
- A idade não pode ser menor ou igual a zero.
- A nota deve estar entre 0 e 100.
- A nota mínima para aprovação é 60 pontos.
- A quantidade de familiares deve ser maior que zero.
- A renda familiar deve ser maior que zero.
- A renda por pessoa é calculada dividindo a renda familiar pela quantidade de familiares.
- A porcentagem da bolsa é definida pela renda por pessoa:

  - Até R$ 800 → 100% de bolsa.
  - Maior que R$ 800 até R$ 1500 → 70% de bolsa.
  - Maior que R$ 1500 até R$ 2500 → 40% de bolsa.
  - Acima de R$ 2500 → Sem concessão de bolsa.
