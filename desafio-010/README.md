# Desafio 010 - Sistema de Produtos e Categorias

Projeto desenvolvido para praticar lógica de programação com JavaScript.

## Objetivos

- Busca de dados
- Filtragem de dados
- Transformação de dados
- Cálculo de valores
- Manipulação de objetos
- Uso de `map()`
- Uso de `filter()`
- Uso de `find()`
- Uso de `reduce()`
- Uso de destructuring
- Uso de rest e spread
- Composição de funções
- Separação de responsabilidades
- Organização de regras de negócio

## Regras

- Um produto deve possuir ID, nome, categoria, preço, estoque e status de atividade.
- Um produto pode ser localizado pelo seu ID.
- A busca por ID deve retornar o produto correspondente ou `undefined` caso não seja encontrado.
- Devem ser identificados somente os produtos ativos.
- Os produtos devem poder ser filtrados por uma categoria informada.
- Produtos disponíveis para venda devem estar ativos e possuir estoque maior que zero.
- O valor total do estoque deve ser calculado multiplicando o preço pela quantidade em estoque de cada produto.
- Deve ser identificado o produto com maior valor total em estoque.
- Devem ser identificados os produtos que estão sem estoque.
- Deve ser gerada uma lista resumida dos produtos, removendo a informação de atividade e adicionando o valor total em estoque.
- O relatório final deve reunir as informações obtidas pelas funções responsáveis por cada regra.
- O relatório deve permitir a consulta dos produtos de uma categoria específica.
